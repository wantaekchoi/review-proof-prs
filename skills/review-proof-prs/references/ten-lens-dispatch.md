# 렌즈 게이트 — 디스패치 레시피

## 어떻게 돌리나

레벨이 정한 수만큼 **독립 read-only 리뷰어 서브에이전트**를 병렬로 띄운다. 각 에이전트에 같은 자료를 준다:
- finding(자기모순 한 문장 + 위치)
- diff(최소 수정)
- RED/GREEN 증거(실제 출력)
- PR 본문(확정본)

그리고 **각자 렌즈 하나**만 배정한다. 각 에이전트는 판정을 반환한다:
`SUBMIT-OK` | `FIX-FIRST(목록)` | `BLOCK(사유)`.

**집계**: 전원 SUBMIT-OK(또는 CONCERN 이 전부 *반영*됨)이어야 제출. 집계는 **다수결이 아니다** —
하나라도 막으면 막힌다.

**고친 뒤에는 해당 렌즈만이 아니라 그 레벨의 렌즈 전원을 다시 돌린다.** 영수증이 본문 해시로 묶이므로
본문을 한 글자라도 고치면 낡은 판정은 전부 죽는다. 재실행은 **델타로** 한다(`lenses/_delta.md`).

## 격리 (필수)

리뷰어는 **read-only**다 — 편집 금지, 공유 클론을 변경하는 빌드 금지. 실행이 필요하면 자기 격리 사본에서.
어기면 stale-artifact 레이스로 가짜 판정이 나온다.

- **격리는 `$HOME` 까지다.** 도구가 `$HOME`·`/tmp`·전역 캐시에 쓰면 워크트리를 갈라도 에이전트끼리 덮어쓴다. 쓰면 에이전트마다 `HOME=<샌드박스>` 로 가른다.
- **실행이 필요한 렌즈에만 샌드박스를 준다.** 전부에 빌드를 주면 CPU 경합 자체가 오판 원인이 된다. 넘기기 전에 샌드박스 하나가 실제로 빌드되는지 먼저 확인한다.

## 디스패치 전 3점 검사

1. **그 agent type 이 조사에 필요한 도구를 갖는가.** Bash 가 없는 리뷰어 타입은 `git show`·`git log`·빌드를 못 돌린다. 필요하면 자료를 파일로 떠서 넘긴다.
2. **조사 대상이 최신인가.** `git fetch` 는 ref 만 갱신하고 워킹트리는 그대로 둔다. 디스패치 전에 워킹트리를 실제로 갱신하고, 브리핑에 **HEAD 해시와 커밋 날짜**를 적는다.
3. **보고서의 실행 주장을 도구 범위와 대조한다.** 그 에이전트가 그 명령을 돌릴 수 없었다면 그 근거는 무효다.

## 부정 판정은 오케스트레이터가 직접 재확인한다

**"~가 없다", "~는 틀렸다"** 는 부재의 증명이라 검색 범위·시점이 조금만 어긋나도 뒤집힌다.
외부로 조치하기 전에 오케스트레이터가 자기 손으로 재현한다. 판정 기준은 "몇 명이 말했나" 가 아니라
"내가 재현했나" 다. 다만 **여러 렌즈가 독립적으로 같은 문장을 지목하면** 거의 항상 진짜다.

## 판정은 파일로 받아라

반환 텍스트가 유실될 수 있다. 프롬프트에 산출물 경로를 박고(`판정을 <경로>/lens-<n>.md 에 써라`),
제출 전에 **파일 개수가 렌즈 수와 맞는지** 센다. 안 맞으면 그 렌즈는 안 돈 것으로 친다.

## 렌즈 정의는 `lenses/` 가 정본이다

렌즈 하나가 파일 하나다. 각 파일은 frontmatter(`id`·`name`·`model`·`effort`)와 그 렌즈가 볼 것만 담는다.
공통 규칙은 `lenses/_guardrails.md`, 델타 규칙은 `lenses/_delta.md` 에 있고 렌즈 파일에는 규칙을 복사하지 않는다.

| 파일 | 렌즈 |
|---|---|
| `0-premise` | 전제 파괴 — **상설.** 다른 렌즈는 "수정이 옳은가" 를 묻느라 전제를 참으로 놓는다 |
| `1-intent` | 회의론/의도 — 메인테이너가 "의도된 동작" 으로 닫을 여지 |
| `2-correctness` | 정확성 — root cause 인가, 증상만 덮는가 |
| `3-edge` | 엣지 — 경계·널·빈값·최대치 |
| `4-sideeffect` | 부작용 — 다른 경로·형제 기능·기존 테스트 |
| `5-mechanism` | 메커니즘/E2E 충실도 — 재현이 실제 사용자 경로인가 |
| `6-verification` | 검증 — hollow test 아닌가 |
| `7-convention` | 컨벤션 — 코드·프로젝트 관례 |
| `8-acceptability` | 수용성 — 범위·정책상 받을 만한가 |
| `9-completeness` | 완결성 — 놓친 형제 결함·미검증 주장 |
| `10-body` | 본문 — 제출물 자체의 사실검증 |

새 렌즈를 더하려면 파일을 하나 더 만들고 `lens-levels.json` 의 레벨에 id 를 넣는다.
렌즈 파일을 고치면 `<플러그인 루트>/scripts/build-lens-agents.sh` 로 `agents/lens-<N>.md`(쓰기 도구 차단)를 다시 만든다.

## 돌리는 법 — 워크플로

`assets/lens-gate.js` 가 카드 매니페스트를 받아 레벨대로 디스패치하고 집계한다. 스크립트에는 렌즈 프롬프트가 없다 —
각 에이전트가 자기 렌즈 파일(또는 에이전트 정의)을 읽는다.

```bash
FIXED=$(<스킬>/assets/lens-args.sh "$PWD")            # levels·lens_meta 를 실물에서 뽑는다
CARDS='[{"key":"...","repo":"...","wt":"...","level":"essential","gist":"..."}]'
python3 -c 'import json,sys; a=json.loads(sys.argv[1]); a["cards"]=json.loads(sys.argv[2]); print(json.dumps(a,ensure_ascii=False))' "$FIXED" "$CARDS"
# → 그 JSON 을 Workflow 의 args 로, scriptPath 는 <스킬>/assets/lens-gate.js
```

`~/.claude/agents/lens-0..10` 이 전부 있으면 `agentType: 'lens-<N>'`, 플러그인으로 설치돼 있으면 `'review-proof-prs:lens-<N>'` 으로 부른다(`LENS_AGENT_PREFIX` 로 덮어쓸 수 있다). 둘 다 아니면 렌즈 파일을 직접 읽힌다.
델타 라운드는 카드에 `changes: ["바뀐 문장 1", ...]` 을 더한다. `body_sha` 가 렌즈끼리 갈리면 스크립트가 경고하고 통과시키지 않는다.

## 규모 — 레벨

| 레벨 | 언제 |
|---|---|
| `premise` | 정답이 소스로 기계적으로 떨어지는 표기 정정 |
| `claim` | 코드가 이미 기계로 증명된 카드, 리뷰 답글 |
| `light` | 빠른 확인 — 전제·root cause·증명 |
| `essential` | 기본값 — light 에 반박 봉쇄와 본문 사실검증을 더한다 |
| `full` | 렌즈 전부 + 독립 반박자 3인 |

**어느 레벨이 어느 렌즈를 몇 개 요구하는지는 [lens-levels.json](lens-levels.json) 이 정본이다.**
판정문 맨 위에 `LEVEL: <이름>` 을 적고, `<플러그인 루트>/scripts/lens-record.sh --level <이름> <본문> <판정문>` 이 정족수·필수 렌즈·본문 해시를 대조해 영수증을 남긴다.

`full` 의 반박자는 "반박해보라. 불확실하면 refuted=true" 를 받고 판정문에 `REFUTE: <id> refuted=<bool>` 로 적는다. 하나라도 `refuted=true` 면 막는다.

## 운용

- **호출 예산을 프롬프트에 처음부터 넣어라** — 벌크 조회 한 방, 테스트 필터로 좁히기, 퍼머링크는 로컬 파일로.
- **죽은 에이전트는 다시 띄우지 말고 이어붙여라.** 재개 메시지에 어디서 끊겼는지 적는다.
- **에이전트가 내 제약에 막히면 제약을 고쳐라** — 인덱스가 필요하면 미리 만들어 두고 "조회만 하면 된다" 고 알린다.
- **고치는 건 전부 회수한 뒤 한 번에.** 지적마다 본문을 고치면 뒤 렌즈가 이미 없는 문장을 지적한다.
- **실행이 없는 렌즈는 경량 모델로 충분하다.** 판정의 질은 모델보다 프롬프트에 실측을 강제했는지에서 갈린다.
