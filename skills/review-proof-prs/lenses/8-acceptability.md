**임무: 메인테이너가 범위·정책상 받을지 본다.**

## 볼 것

- **대량 리팩터·현대화로 읽히지 않는가.** 범위가 커지면 거절 확률이 오른다.
- **base 브랜치가 맞는가.** 버전 이름이 붙었다고 기여 타깃인 게 아니다 —
  머지된 외부 PR 의 base 분포로 정한다.
- **선점.** 열린 PR·최근 머지·브랜치 이름까지 본다. 제목만 훑지 말고 후보가 확정될 때마다
  처음 뽑은 목록으로 돌아가 하나씩 대조한다.
- **CONTRIBUTING 의 AI·LLM 조항**을 확인했는가. 금지 조항이 있으면 사람이 자기 말로 쓴다 — 윤문은 저자 요건을 못 넘는다.
- **삭제 PR 이면 코드 밖 잔재를 훑었는가** — 아키텍처 문서·README 모듈 목록·CHANGELOG 분류·
  로케일 키·CSS 클래스·아이콘·픽스처. 코드 참조 0건이어도 문서가 남으면 "불완전한 삭제" 로 막힌다.
