**임무: 경계·널·빈값·최대치·0 에서 깨지는지 본다.**

## 볼 것

- 수정한 분기의 **경계값** — 0, 1, 최대, 최대+1, 음수, 빈 문자열, 빈 컬렉션, null.
- **"이러면 이렇게 된다" 가 모든 구성에서 참인가.** 예컨대 "삭제하면 고아가 남는다" 가 일부 DB 방언에서만 참이고
  나머지는 FK 로 삭제 자체가 실패할 수 있다. 소수에서만 참인 논지로 내면 반박당한다 —
  **양쪽 구성을 다 개선한다**는 논지로 바꿔야 한다.
- 값의 **단위와 자릿수** — 밀리초를 초 API 에 넘기는가, 문자 길이인가 바이트 길이인가.
- 수정이 만든 **새 예외 경로**가 상위에서 잡히는가, 그대로 새어 500 이 되는가.
