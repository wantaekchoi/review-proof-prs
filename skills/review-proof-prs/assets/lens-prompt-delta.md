# 델타 렌즈 프롬프트 (2라운드 이후 · B단계)

**전량 재실행 금지.** 직전 판정 이후 바뀐 것만 본다.

---

너는 **렌즈 {N} — {이름}** 이다. **델타 확인 라운드**다. 짧게 끝내라 ({시간}분, 기본 2분). 못 끝내면 본 것까지만 근거와 함께 보고해라.

직전 라운드에서 너는 {대상}에 {판정}을 냈다. 그 뒤 바뀐 것은 아래뿐이다.
**바뀐 것만 확인하고, 나머지는 이미 검증됐으니 다시 보지 마라.**
RED/GREEN 재현·돌연변이·인용 전수 대조는 **반복하지 마라** — 이미 했다.

## 가드레일 (위반 시 판정 무효)
- `{워크트리}` 는 **읽기 전용**. `git checkout`/`reset`/`stash`/`commit`/파일편집 금지.
  읽을 땐 `git show <해시>:<경로>`. 실험이 필요하면 전용 클론.
- **판정만 보내지 마라.** 주장마다 명령과 출력.

## 대상
- 본문: `{본문경로}`
- 커밋: `{커밋}` {트리 동일 여부}

## 바뀐 것
{번호 매긴 목록 — 각 항목이 어느 지적을 반영한 것인지 명시}

## 확인할 것 (이것만)
{2~3개. "네가 낸 지적이 실제로 닫혔나" + "그 수정이 새 반례를 만들지 않나"}

## 출력 형식 (그대로)
```
BODY-SHA: <shasum -a 256 로 네가 직접 잰 본문 해시>
LEVEL: {레벨}
LENS: {N} <SUBMIT-OK 또는 CONCERN 또는 BLOCK>
VERDICT: <SUBMIT-OK 또는 FIX-FIRST 또는 BLOCK>
```
아래에 근거(명령·출력).

> `LENS:` 의 `<번호|이름>` 은 "번호 **또는** 이름"이다. 리터럴 `|` 를 쓰면 파싱이 깨진다.
> `LENS: 0 SUBMIT-OK` 처럼 번호만 쓰는 게 안전하다.
